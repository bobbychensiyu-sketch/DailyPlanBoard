## 核心特性

### 1. 极致轻量、原生流畅
* **极小体积**：零第三方重型框架（无 Electron / WebView2），框架依赖单文件约 **460 KB**。
* **极低占用**：软件渲染管线 + 闲置工作集内存裁剪，后台常驻内存仅约 **10~20 MB**。
* **纯本地隐私存储**：计划与设置数据仅保存在程序同级 `data/` 目录下的本地 JSON 文件中（自动生成 `.backup.json` 备份），无任何遥测或云端上传。

### 2. 计划节点时间（Milestone）跨天联动与三级紧急预警
* **快捷设定节点**：
  * 输入框直接支持内联日期语法（如 `提交设计方案 @11-28`、`节点:2026-12-05`、`截止12-01`）；
  * 或点击快捷栏 `🎯 节点` 按钮一键选定（`+3天` / `+5天` / `+1周` / `+2周` / `月底` / 日历自选）。
* **自动跨天填充**：设定节点日期后，系统自动将计划填入**从起始日到节点截止日之间的每一天**并绑定同一关联组。
* **动态倒计时胶囊**：每天的任务卡片自动显示距离节点剩余天数胶囊：
  * **当天截止（T-0）**：`🚨 今日节点 · 紧急`（红框高亮，自动升格为最高优先级）
  * **提前 1 天（T-1）**：`🔥 剩1天 · 提前1天`
  * **提前 3 天（T-3）**：`⚠️ 剩3天 · 提前3天`
  * **其余工作日**：`⏳ 剩 N 天`
* **三阶段自动告警**：提前 3 天、提前 1 天与节点当天自动触发提醒；当天触发**红框紧急弹窗 + 系统警示音 + 托盘气泡 + 企业微信高危告警推送**。
* **系列批量管理**：右键菜单支持「整个节点系列全部标为完成」或「删除整个节点系列计划」。

### 3. 屏幕边缘磁吸胶囊与 Z 序置顶自愈
* **靠边自动吸附与胶囊收起**：靠近屏幕左/右边缘自动磁吸对齐，点击顶栏 `◧`（或按 `Ctrl + W`）折叠为轻量侧边胶囊并实时显示今日待办角标；鼠标移出展开的看板约 180ms 即自动平滑收回。
* **悬停即览、点击固定**：鼠标悬停在边缘胶囊上自动展开预览/勾选；单击胶囊固定展开；拖拽胶囊可上下调节高度或跨屏幕中线换边。
* **全方位拉伸调节**：展开后支持四边与四角自由拖拽调节大小，调整期间自动防误收起并记忆尺寸。
* **置顶 Z 序自动巡检自愈**：针对 Windows 打开新软件/弹框后容易抢占 TopMost Z 序的问题内置静默巡检自愈机制，不抢占焦点、不遮挡系统开始菜单/输入法；配合精准的**全屏程序自动避让**（仅对真正的全屏游戏、全屏视频、F11 浏览器和 PPT 放映退避，不误判普通最大化软件）与**防误关闭/最小化保护**。

### 4. 默认提醒、次日自动顺延 & 多渠道通知
* **智能默认规则**：支持开关「新增计划默认提醒」（默认 `18:00`），也可用内联时间（如 `15:30 会议`）或快捷按钮单独覆盖。
* **未完成自动顺延**：支持开关「未完成计划次日自动顺延」及次日早上提醒（默认 `09:00`）。
* **多路提醒联动**：桌面置顶交互式提醒卡片（支持一键完成 / 推迟 10 分钟 / 30 分钟 / 1 小时）+ 系统提示音 + Windows 托盘气泡 + **企业微信群机器人（WeCom Bot）Webhook 推送**。

### 5. 日历总览、区间报告导出 & 多语言
* **月历总览视图（`📅` / `Ctrl + M`）**：在月历网格直观查看每天已完成/总计徽标及节点倒计时，支持快速跨日切换。
* **一键导出汇报**：自由选择起止日期（或本周 / 本月 / 近 7 天），一键导出为 **Markdown 报告 (`.md`)** 或 **CSV 表格 (`.csv`)**，亦可一键发送当日汇总到企业微信群。
* **三语界面 & 个性外观**：支持 **简体中文 / English / Français** 实时切换；内置 5 套护眼配色主题（暖纸 / 素白 / 松林 / 晚霞 / 墨夜）、透明度调节、字号缩放与**屏幕共享/截图隐私隐藏**。

## 快速使用与源码构建

### 环境要求
* Windows 10 / 11 (x64)
* 运行直接下载的二进制需要 [.NET 7+ Desktop Runtime (x64)](https://dotnet.microsoft.com/download/dotnet)
* 从源码编译需要 **.NET 7.0 SDK** 或更高版本（项目配置了 `<RollForward>Major</RollForward>`）

### 从源码构建

```powershell
# 克隆仓库
git clone https://github.com/bobbychensiyu-sketch/DailyPlanBoard.git
cd DailyPlanBoard

# 编译 Release 版本
dotnet build .\src\DailyPlanBoard.csproj -c Release

# 发布单文件绿色版（依赖本机 .NET Desktop Runtime）
dotnet publish .\src\DailyPlanBoard.csproj -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o .\publish
```

> 若希望打包为完全免安装运行时（Self-Contained）的单文件版本，可将 `--self-contained false` 改为 `--self-contained true`。
